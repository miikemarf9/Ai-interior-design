# Interior platform — Stage 1

Stage 1 establishes the accessible-premium visual system, core route structure and reusable recommendation explanation pattern for a UK-first interior-design and commerce platform.

## Run locally

```bash
npm install
npm run dev
```

## Current routes

- `/` — Stage 1 brand/foundation preview
- `/style-guide` — internal design system
- `/design` — stable entry route reserved for the Stage 3 intake

## Important

`Roomfound` is a working name only and is isolated in `lib/site.ts` / the shared Brand component so it can be replaced easily.

The homepage is intentionally not considered final in Stage 1. Stage 2 is the dedicated premium-homepage build.
